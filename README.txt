またあとワニさん　動作確認版

【起動方法】
1. このフォルダを開きます。
2. コマンドプロンプトで次を実行します。
   pip install -r requirements.txt
3. 続けて次を実行します。
   streamlit run app.py

【この版で確認できること】
・日記の作成（みんな／自分だけ）
・新着順の日記表示
・本人にだけ分かるリアクション
・返信予定の表示と変更
・手紙送信とワニさんの簡易演出
・名前検索
・プロフィール編集
・見ないキーワード
・ミュートとブロック

【動作確認版の制限】
入力内容はブラウザを閉じると消える場合があります。
本物のユーザー登録、複数ユーザー間の通信、通知、通報送信は未接続です。
